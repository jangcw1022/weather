| 항목 | 내용 |
|---|---|

## 1. 제품 정의

도시 이름을 검색하면 해당 도시의 **현재 기상**과 **7일 예보**를 보여주는 단일 페이지 웹앱.
날씨 상태와 현지 낮/밤 여부에 따라 **화면 전체의 배경이 변한다**.

### 1.1 목표

| 목표 | 판단 기준 |
|---|---|
| 최소 조작으로 날씨 확인 | 도시 입력 → 후보 선택 → 결과까지 2단계 |
| 숫자를 읽지 않아도 전달되는 정보 | 배경색으로 날씨/시간대, 막대로 주간 기온 추세 인지 |
| 실패해도 막히지 않는 경험 | 모든 실패 케이스에 다음 행동(재시도/재검색)이 화면에 존재 |

### 1.2 v1 범위

| 포함 | 제외 (향후) |
|---|---|
| 도시명 검색(한/영), 현재 날씨, 7일 예보, 상태 화면 3종, 동적 배경, 모바일 반응형 | 랜드마크 클릭 진입, 대륙/날씨/기온 필터, 도시 리스트 뷰, 즐겨찾기, 시간별 예보 |

> 랜드마크·필터·리스트는 초기 기획에 있었으나 v1에서는 검색 기반으로 범위를 축소했다. §8 참조.

## 2. 사용자 시나리오

1. 진입 → 대기 화면(🧭)과 바로가기 도시 5개 노출
2. 검색창에 `서울` 또는 `Seoul` 입력 → 300ms 후 후보 목록 표시
3. 후보 선택 → 로딩 → 현재 날씨 + 7일 예보 표시, 배경이 해당 날씨·시간대로 전환
4. 검색 결과가 없으면 → 미발견 화면, 영문 재검색 유도
5. API 실패/타임아웃 → 에러 화면, **다시 시도** 버튼으로 동일 요청 재호출

## 4. 기능 명세

### 4.1 도시 검색

| 항목 | 사양 |
|---|---|
| 엔드포인트 | `GET https://geocoding-api.open-meteo.com/v1/search` |
| 파라미터 | `name`, `count=8`, `language=ko`, `format=json` |
| 한글 폴백 | `language=ko` 결과가 0건이면 `language=en`으로 1회 재조회 |
| 트리거 | 입력 1자 이상, 300ms 디바운스 |
| 후보 표시 | 1행 = 도시명 / 2행 = `admin1 · country` (동명 도시 구분) |
| 키보드 | ↑ ↓ 이동, Enter 선택, Esc 닫기, `aria-activedescendant` 갱신 |
| 닫힘 조건 | 외부 영역 클릭, Esc, 도시 선택 |

### 4.2 날씨 조회

| 항목 | 사양 |
|---|---|
| 엔드포인트 | `GET https://api.open-meteo.com/v1/forecast` |
| 공통 | `latitude`, `longitude`, `timezone=auto`, `forecast_days=7` |
| `current` | `temperature_2m`, `apparent_temperature`, `relative_humidity_2m`, `wind_speed_10m`, `weather_code`, `is_day` |
| `daily` | `weather_code`, `temperature_2m_max`, `temperature_2m_min` |
| 검증 | `current` 또는 `daily` 누락 시 에러 화면으로 전환 |

### 4.3 현지 시각

| 항목 | 사양 |
|---|---|
| 산출 | `Date.now() + utc_offset_seconds × 1000` 후 UTC 게터로 시·분·초 추출 |
| 갱신 | 1초 간격, 화면 전환 시 타이머 해제 |
| 표기 | `HH:MM:SS` + `timezone_abbreviation` |

### 4.4 7일 예보 — 기온 범위 막대

| 항목 | 사양 |
|---|---|
| 스케일 | 7일 전체의 최저값~최고값을 하나의 축으로 사용 |
| 막대 위치 | `top = (주간최고 − 당일최고) / 스팬 × 100%` |
| 막대 길이 | `height = (당일최고 − 당일최저) / 스팬 × 100%`, 최소 3% |
| 강조 | 첫 칸은 라벨을 `오늘`로, 강조색 적용 |
| 스크롤 | 모바일 가로 스크롤(칸 너비 62px), `sm` 이상에서 7칸 균등 분배 |

## 5. 상태 화면

| 상태 | 트리거 | 구성 |
|---|---|---|
| 대기 (Idle) | 최초 진입 | 🧭 + 안내 문구 + 바로가기 도시 5개 |
| 로딩 | 날씨 조회 중 | 실제 레이아웃과 동일한 형태의 스켈레톤, `aria-busy="true"` |
| 미발견 | 지오코딩 결과 0건 (ko/en 모두) | 🔍 + 입력한 검색어 반영 + **다시 검색**(입력창 포커스) |
| 에러 | fetch 실패, HTTP 4xx/5xx, 응답 형식 오류, 타임아웃 | ⚠️ + 원인 메시지 + **다시 시도**(마지막 요청 재호출), `role="alert"` |

- 타임아웃: `AbortController` 기준 **10초**, 검색·날씨 조회 양쪽 적용
- 재시도는 마지막으로 선택한 도시 좌표(`lastPlace`)를 그대로 재사용

## 7. 디자인 시스템

### 7.1 컨셉

**기상 관측소 기록지** — 얇은 괘선, 모노스페이스 데이터 라벨, 라운딩 없음. 장식 대신 계측기의 문법을 쓴다.

### 7.2 토큰

| 역할 | 값 |
|---|---|
| 본문 서체 | Pretendard Variable |
| 수치·라벨 서체 | JetBrains Mono (300 / 400 / 500) |
| 기온 표시 | `clamp(5.5rem, 27vw, 14rem)`, weight 300, `tabular-nums` |
| 라벨 | 11px / letter-spacing `.16em` / 대문자 |
| 강조색 | 낮 `#C77700` · 밤 `#FFB300` |
| 잉크 (낮) | `#10151C` |
| 잉크 (밤) | `#EEF2F6` |
| 패널 | 반투명 + `backdrop-filter: blur(14px)` |

### 7.3 배경 (동적)

`weather_code` 그룹 × `is_day` → 12종 그라디언트. 전환 0.9초.
밤 배경에서는 잉크/패널 값이 전부 반전되어 텍스트 대비를 유지한다.

| 그룹 | 낮 | 밤 |
|---|---|---|
| clear | `#4C9BE0 → #DCEAF2` | `#0B1533 → #1C2A4A` |
| cloud | `#93A9BC → #DFE5E9` | `#11182A → #2A3242` |
| fog | `#C3C7C8 → #E9EAEA` | `#1A1D24 → #333941` |
| rain | `#5F7488 → #C4CED6` | `#0A1220 → #212C3B` |
| snow | `#A9BFD2 → #F0F4F7` | `#121C2E → #2E3A4D` |
| storm | `#4A4257 → #A9A3B4` | `#0C0A16 → #241F33` |

### 7.4 반응형

| 브레이크포인트 | 레이아웃 |
|---|---|
| 기본 (모바일) | 1단 세로 스택, 최대 폭 없음, 7일 예보 가로 스크롤 |
| `sm` (640px~) | 좌우 여백 확대, 지표 좌측 정렬 |
| `md` (768px~) | `max-w-3xl` 중앙 정렬, 7일 예보 7칸 균등 분배 |

## 8. 비기능 요구사항

| 항목 | 사양 |
|---|---|
| 접근성 | `role="combobox"` / `listbox` / `option`, 키보드 전체 조작, 이모지에 `aria-label`, 에러 `role="alert"`, `:focus-visible` 아웃라인 |
| 모션 | `prefers-reduced-motion: reduce` 시 모든 애니메이션·트랜지션 비활성 |

| 성능 | 검색 디바운스 300ms, 외부 JS 라이브러리 없음 |
| 브라우저 | `backdrop-filter`, `AbortController` 지원 최신 브라우저 |
